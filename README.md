# Batirium

Site vitrine **conceptuel** (projet de démonstration) pour une entreprise fictive de construction et d'architecture, avec un second microsite autonome : **Maison Nue**, studio de coiffure (`/maison-nue/`).

- HTML / CSS / JavaScript natif, sans build
- Multi-page : accueil, réalisations (3 études de cas), agence, contact
- Responsive, filtres de projets, modale d'étude de cas, transitions entre pages
- Les formulaires sont des démos : aucun message n'est envoyé

## Lancer en local

Le site utilise des chemins à la racine (`/styles.css`) : il doit être servi par un serveur, pas ouvert directement.

```bash
npm run dev
```

## Déploiement

Dépôt statique, déployable tel quel sur Vercel (aucune configuration requise).
